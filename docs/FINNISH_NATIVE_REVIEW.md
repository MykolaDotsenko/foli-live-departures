# Native Finnish review

Automated translation completeness proves that every interface phrase has a Finnish entry. It does not prove that a stressed passenger would understand the wording naturally.

Have a native Finnish speaker review the production UI on a phone.

## P0 safety copy

Review aloud and on screen:

- [ ] get ready / next-stop wording;
- [ ] STOP-button instruction;
- [ ] get-off-now instruction;
- [ ] missed-stop recovery;
- [ ] transfer catchability and recovery;
- [ ] cancellation/disappearance/degraded-data wording;
- [ ] spoken announcements;
- [ ] Show to driver card.

Criteria:

- short enough to read at a glance;
- natural Finnish, not translated-English structure;
- imperative meaning is unambiguous;
- uncertainty is not phrased as certainty;
- stop names are not incorrectly inflected;
- terms match normal Föli/passenger vocabulary where appropriate.

## General UI

Review:

- [ ] destination search and official-planner handoff;
- [ ] Home/School/Work setup;
- [ ] offline/error states;
- [ ] iPhone installation hint;
- [ ] About/privacy;
- [ ] accessibility labels read naturally with VoiceOver/TalkBack.

Record every accepted wording change in the normal translation tests so the Finnish completeness gate continues to protect it.
