Turku Departures

Privacy policy

Last updated: 3 October 2026

Turku Departures is an independent transit companion made by Mykola Dotsenko. It uses Föli open data but is not made by or affiliated with Föli or the City of Turku.

Privacy in one sentence

There is no account. No advertising SDK or analytics SDK is included. Saved app state stays on your device; optional device location is processed on your device and is not sent by Turku Departures to the developer or to Föli.

Data stored on your device

Depending on the features you use, the app can store locally:

  • favourite and recent public stop identifiers;
  • line filters and My Places made from public stop numbers/names, not street addresses;
  • recent departure-board responses for a short offline-recovery window;
  • an active Ride Mode session for at most six hours;
  • local preferences and recent same-session search results.

Turku Departures does not operate an account database. You can remove locally stored data by using the app's local-data controls, clearing the site's/app's storage, or uninstalling the Android app.

Device location

Location is optional. It is used to find nearby stops, to power Stop Radar while that panel is open and, when you enable location backup in Ride Mode, to compare your position with the selected public-transit route. Stop Radar can also use device orientation or recent direction of travel to point toward a selected public stop. Raw device coordinates are not saved by Turku Departures and are not sent by Turku Departures to the developer or to Föli.

The Android build can additionally offer a per-ride foreground-service companion. It is off by default, requires an explicit opt-in for that ride, receives only an opaque ride identifier and expiry time, and does not persist route, destination or GPS data. The app does not request Android background-location permission.

Network requests

The Android app bundles its web interface locally. The public web/PWA version is served by GitHub Pages, so GitHub can receive ordinary web request information such as an IP address under GitHub's own policies.

Transit data is requested over HTTPS from data.foli.fi. Requests can contain public stop, route or trip identifiers, the stop search text you submit, and during Ride Mode the selected exit stop and nearby trip/stop identifiers needed to refresh transit evidence. Föli's servers can receive the request and network information such as your IP address. Turku Departures does not use those requests for advertising, profiling or analytics.

Direct address/place lookup is disabled in the production app. Address and place text entered there stays on the device; the app offers the official Turku journey planner as an external link instead. Google Maps is opened only when you explicitly tap a route link, after which Google's own terms and privacy policy apply.

Diagnostics and reports

The app has no automatic crash-reporting or analytics service. Optional field diagnostics are created locally. They leave the device only if you explicitly choose to copy or send them. Problem-report and email links likewise open an external service only after your action.

Security and retention

Automatic app network requests use HTTPS. Turku Departures does not sell personal data. Because the developer does not run an account or analytics backend for this app, there is no developer-side user profile to delete. Third-party services named above handle their own server logs according to their policies.
